01/ about

I'm a double-degree student at the University of West Florida pursuing a B.S. in Computer Science and a B.S. in Cybersecurity, with a minor in the Honors Pathway. My work sits at the intersection of machine learning and network security — I build unsupervised anomaly-detection models on real network traffic data and study how AI is reshaping both offense and defense in cybersecurity. I've co-authored two peer-reviewed publications and stay active in the field through cybersecurity clubs, collegiate defense competitions, and capture-the-flag events.

04/ projects

Unsupervised Intrusion Detection Using K-Means and BIRCH Clustering

Developed unsupervised ML clustering models for anomaly detection using network traffic logs from UWF Zeek Data in Apache Spark/PySpark.

  • Achieved 99% attack-detection accuracy using an optimized 325-cluster K-Means configuration on the UWF-ZeekDataFall22 dataset.

Reviewed AI applications in cybersecurity — generative AI, LLMs, cyber-physical systems, and ethical implications — published in a peer-reviewed journal.
